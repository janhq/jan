# Jan V1

[Jan-V1](https://huggingface.co/janhq/Jan-v1-4B) is the first release in the Jan
family, built for agentic reasoning and tool use inside [Jan](/). It's based on
the [Lucy](https://huggingface.co/Menlo/Lucy) model.

For setup and prompting guidance, see the
[Jan V1 research cookbook](/post/jan-v1-for-research).
