# Python Quickstart

**Run a script that asks Jan a question and prints its answer as it arrives.**

You need **Python 3.11+**, **Git**, and access to a model provider. No Node.js, Jan Desktop or Rust
toolchain is needed. Python talks directly to the Jan runtime.

<Callout type="warning">
The SDK is a preview and is not published to PyPI yet. Install the source package below, not
`pip install jan-agent-sdk`. The runtime is a separate, prebuilt download.
</Callout>

<Steps>

```bash
cd jan-python-demo
```

### Connect a model

Sign in to Tokamak:

```bash
jan login
```

Or [configure your own provider](/docs/agent/quickstart#connect-a-provider). Both the CLI and SDK
use Jan's provider configuration. If you have already configured Jan, skip this step.

### Save and run the script

Save this complete example as `hello.py` in `jan-python-demo`:

```python filename="hello.py"
from jan_agent_sdk import JanRuntime

with JanRuntime.start() as runtime:
    session = runtime.create_session(ephemeral=True, builtins=False)
    turn = session.prompt("Explain what a mutex is in one sentence.")

    for event in turn:
        if event["type"] == "token":
            print(event["text"], end="", flush=True)

    result = turn.result()
    if result.stop_reason == "error":
        raise RuntimeError(result.error)
    print(f"\nFinished: {result.stop_reason}")
```

```bash
python hello.py
```

The answer depends on your model. A successful run prints answer text followed by
`Finished: completed`.

</Steps>

## What just happened?

- `start()` launched the Jan runtime and checked its protocol version.
- `create_session()` created a conversation. `ephemeral=True` avoids saving it; `builtins=False`
  disables built-in and external tool sources, so this first example only answers a question.
- `prompt()` started a turn. Each `token` event contains another piece of the answer.
- `result()` returned the final status. Leaving the `with` block closed the runtime, including
  when an exception occurred.

Send another prompt on the same `session` to continue the conversation. To select a specific
configured model, add `model="provider/model-id"` to `create_session()`.

The Python API is synchronous: iterating a turn waits for events. In an async application, run
blocking SDK work in a worker thread rather than on your event loop.

## If it fails

| Problem | What to do |
| --- | --- |
| `ModuleNotFoundError: jan_agent_sdk` | Activate the demo's virtual environment and run the local `pip install` above with that Python. |
| Cannot start `jan` | Add it to PATH, or pass its absolute path as `JanRuntime.start(bin="/path/to/jan")`. |
| Unknown `rpc` command or protocol mismatch | Run `jan update`, then retry startup. |
| No model, authentication error, or provider error | Run `jan login` or fix the provider configuration. A model override must name a model that provider serves. |

See [Process & failures](/docs/agent/sdk-runtime) for error handling in an application.
