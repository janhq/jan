# Agent SDK

Want to put Jan Agent inside your own application? Start with the transport you can use today.
The JavaScript and Python SDK packages are not released, so there is no SDK package to install or
SDK quickstart to run yet. [The Agent quickstart](/docs/agent/quickstart) is for using Jan from a
terminal, not for embedding an SDK.

## Choose your path

| You want to | State | Start here |
| --- | --- | --- |
| Use Jan interactively or run a one-shot CLI task | Available in the Jan CLI | [Agent quickstart](/docs/agent/quickstart) and [CLI reference](/docs/agent/cli) |
| Embed the current `stream-json` CLI transport | Shipped; your application owns the Jan process and stdin/stdout | [CLI `run` and `schema` reference](/docs/agent/cli#streaming-json-in-both-directions) and [generated record guide](/docs/agent/protocol) |
| Embed addressable sessions with RPC | Merged in [PR #9049](https://github.com/janhq/jan/pull/9049); not in a release yet | [CLI `rpc` reference](/docs/agent/cli#rpc) and [generated record guide](/docs/agent/protocol) |
| Let the model call tools your application runs | Available over `stream-json` (`--host-tools`) and RPC (`session/start` `tools`, `tool/respond`); not in a release yet | [RPC host tools](/docs/agent/protocol#rpc-host-tools) and [CLI `run` reference](/docs/agent/cli#streaming-json-in-both-directions) |
| Build a JavaScript or TypeScript app with the SDK | Planned; package not released ([#367](https://github.com/janhq/jan-internal/issues/367)) | Use `stream-json` now, or wait for the JS/TS SDK quickstart |
| Build a Python app with the SDK | Planned; package not released ([#367](https://github.com/janhq/jan-internal/issues/367)) | Use `stream-json` now, or wait for the Python SDK quickstart |

<Callout type="warning">
No JavaScript or Python Jan Agent SDK package is installable yet. RPC is merged but not in a
release, and it is a transport, not an SDK. Host tool callbacks work on both transports: declared,
correlated by request id, answered with text or content parts, and cancelled on interrupt.
</Callout>

## Guides and recipes on the way

These are planned pages, not links to runnable examples or released APIs:

| Planned page | What it will cover | What it waits for |
| --- | --- | --- |
| JavaScript / TypeScript quickstart (`sdk-ts.mdx`) | First embedded turn, streamed outcome, one host tool, close | Released JS/TS SDK and host callbacks |
| Python quickstart (`sdk-python.mdx`) | Direct Python runtime, first turn, host tool, close without Node | Released Python SDK and host callbacks |
| Host tools (`sdk-tools.mdx`) | Callback validation, correlated results, permission and active tools as SDK calls | Released SDKs (the wire contract is in [RPC host tools](/docs/agent/protocol#rpc-host-tools)) |
| Images (`sdk-images.mdx`) | Prompt images, image-bearing results and sampled capture | Corresponding runtime and SDK support |
| Runtime and failures (`sdk-runtime.mdx`) | Process ownership, shutdown, permission and recovery | Released SDK runtime contract |
| Migration (`sdk-migration.mdx`) | Moving an existing `stream-json` harness to an SDK | Released SDKs and feature parity |
| Examples (`sdk-examples.mdx`) | Task-based index of checked-in, verified recipes | Runnable released-SDK examples |

For wire shapes you can inspect today, use the [generated protocol records](/docs/agent/protocol).
