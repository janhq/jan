# Tokamak

Tokamak is the org-level self-hosted AI backend: a router, a fusion model
(Tokamak-1), and governance/audit for every request your agents make.

Part of the open model ecosystem — choose your model, build your agent, run
it yourself. Jan is the alternative to cloud cowork; Tokamak is what runs
behind it when you self-host.

- **[Install](/docs/tokamak/install)** — run Tokamak on your own
  infrastructure.
- **[Connect an agent](/docs/tokamak/connect-agent)** — point a Jan agent at
  your Tokamak instance for model switching, governance, and audit.
