# OrcaRouter

## Integrate OrcaRouter with Jan

[OrcaRouter](https://www.orcarouter.ai/) is an OpenAI-compatible model routing gateway that provides
access to many models from different vendors (OpenAI, Anthropic, Google, DeepSeek, xAI and more)
through a single API and a single API key.

Jan supports the OrcaRouter API, so you can reach models from multiple providers without collecting an
API key from each one. OrcaRouter's `orcarouter/auto` router can also pick a suitable upstream model
per request based on cost, latency, and quality.

<Steps>

### Step 1: Get Your API Key
1. Visit the [OrcaRouter Console](https://www.orcarouter.ai/console) and sign in
2. Create & copy a new API key or copy your existing one (keys start with `sk-orca-`)

<Callout type='info'>
Ensure your API key has sufficient credits. OrcaRouter credits work across all available models.
</Callout>

### Step 2: Configure Jan

1. Navigate to the **Settings** page (<Settings width={16} height={16} style={{display:"inline"}}/>)
2. Under **Model Providers**, select **OrcaRouter**
3. Insert your **API Key**

### Step 3: Start Using OrcaRouter Models

1. Pick any existing **Chat** or create a new one
2. Select any model from **model selector** under OrcaRouter
3. Start chatting
</Steps>

## Available Models Through OrcaRouter

For custom configurations:

**Model Field Settings:**
- Specify a model using the format: `provider/model-name`
- Use `orcarouter/auto` to let OrcaRouter route each request automatically
- The full catalog is available in [OrcaRouter's model list](https://www.orcarouter.ai/models)

**Examples of Model IDs:**
- Adaptive routing: `orcarouter/auto`
- OpenAI GPT-5.5: `openai/gpt-5.5`
- Anthropic Claude Opus 4.8: `anthropic/claude-opus-4.8`
- Google Gemini 3.5 Flash: `google/gemini-3.5-flash`

## Troubleshooting

Common issues and solutions:

**1. API Key Issues**
- Verify your API key is correct and not expired
- Check if you have sufficient credits in your OrcaRouter account
- Ensure you have access to the model you're trying to use

**2. Connection Problems**
- Check your internet connection
- Look for error messages in [Jan's logs](/docs/desktop/troubleshooting#how-to-get-error-logs)

**3. Model Unavailable**
- Confirm the model is currently available on OrcaRouter
- Check if you're using the correct model ID format (`provider/model-name`)
