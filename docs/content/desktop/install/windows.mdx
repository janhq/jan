Jan runs on Windows 10 and higher, supporting NVIDIA, AMD, and Intel Arc GPUs.

## Install Jan

<Steps>

### Download

<DownloadButton href="https://app.jan.ai/download/latest/win-x64">Download Jan for Windows (x64)</DownloadButton>

On a Windows on ARM PC, get the **ARM64** installer from the [download page](https://jan.ai/download) instead.

### Install

1. Run the downloaded `.exe` file
2. Wait for installation to complete
3. Launch Jan

</Steps>

## Compatibility

- **Operating System:** Windows 10 or higher
- **CPU:** x64 with AVX2 support — Intel Haswell (2013+), AMD Excavator (2015+) — or ARM64 (Windows on ARM)
- **Memory:** 8GB minimum (16GB recommended)
- **GPU:** 6GB VRAM minimum for NVIDIA, AMD, or Intel Arc GPUs
- **Storage:** 10GB free space minimum

## Jan Data Folder

Jan stores all your data locally — downloaded models, conversation threads, settings, and logs generated from using the app. Nothing is sent to the cloud.

Default location:

```sh
~\Users\<YourUsername>\AppData\Roaming\Jan\data
```

See [Jan Data Folder](/desktop/data-folder) for details.

## GPU Acceleration

<Tabs items={['NVIDIA GPU', 'AMD GPU', 'Intel Arc GPU']}>

<Tabs.Tab>

<Steps>

### Step 1: Verify Hardware & Install Dependencies
**1.1. Check GPU Detection**

Verify GPU is recognized:
- Right-click desktop > NVIDIA Control Panel
- Or check Device Manager > Display Adapters

**1.2. Install the NVIDIA driver**

Install a current [NVIDIA driver](https://www.nvidia.com/en-us/drivers/) supported by your GPU, then verify detection:

```sh
nvidia-smi
```

Jan bundles its CUDA 13 engine and runtime libraries. You do not need to install the CUDA Toolkit or run `nvcc`. GPUs or drivers that cannot use CUDA 13 use Vulkan instead; keep your GPU's Vulkan-capable driver installed. See [Hardware Backends](/desktop/local-engine/llama-cpp#hardware-backends).

### Step 2: Enable GPU Acceleration

Navigate to **Settings** (<Settings width={16} height={16} style={{display:"inline"}}/>) > **Hardware** > **GPUs**
and toggle the **ON** switch if not enabled.

</Steps>

</Tabs.Tab>

<Tabs.Tab>

Jan uses the bundled Vulkan backend for AMD GPUs. Install a current AMD graphics driver with Vulkan support; no separate HIP/ROCm backend download is needed.

If you need HIP on a supported AMD GPU, run a HIP build of `llama-server` separately and connect it as an [OpenAI-compatible custom endpoint](/desktop/remote-models/custom-endpoint#use-a-different-llamacpp-version). This does not replace Jan's bundled engine; the old backend selector is no longer available.

Verify your GPU appears in **Device Manager** > **Display Adapters**, then navigate to **Settings** (<Settings width={16} height={16} style={{display:"inline"}}/>) > **Hardware** > **GPUs** and turn on its switch if disabled.

</Tabs.Tab>

Intel Arc GPUs require **Vulkan** support.

Navigate to **Settings** (<Settings width={16} height={16} style={{display:"inline"}}/>) > **Hardware** > **GPUs**
and toggle the **ON** switch if not enabled.

## Uninstall Jan

<Steps>

### Step 1: Remove Application through Control Panel

1. Open **Control Panels**
2. Go to **Programs** section
3. Click **Uninstall Program**
4. Search for **Jan**
5. Click the **Three Dots Icon** > **Uninstall**
6. Click **Uninstall** again to confirm
7. Click **OK**

### Step 2: Clean Up Remaining Files

Remove app data:

1. Navigate to `C:\Users\[username]\AppData\Roaming`
2. Delete Jan folder

or via **Terminal**:

```sh
cd C:\Users\%USERNAME%\AppData\Roaming
rmdir /S Jan
```
</Steps>

<Callout type="warning">
Deleted data folders cannot be recovered. Backup important data first.
</Callout>
