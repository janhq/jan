Instructions for installing Jan on Linux. In the `.deb` and AppImage commands below, replace `{version}` with the version in your downloaded filename (without a leading `v`). Run each command from the directory containing that file. For example, a file named `Jan_0.8.6_amd64.deb` uses `0.8.6` in place of `{version}`.

## Install Jan

<Callout type="info">
**Flatpak is the recommended way to install Jan on Linux.** It runs on any distribution and updates automatically through Flathub. Use the `.deb` or AppImage only if you can't use Flatpak.
</Callout>

<Tabs items={['Flatpak (recommended)', '.deb (Ubuntu/Debian)', 'AppImage']}>
<Tabs.Tab>

Install from [Flathub](https://flathub.org/apps/ai.jan.Jan):

```bash
flatpak install flathub ai.jan.Jan
```

Then launch it:

```bash
flatpak run ai.jan.Jan
```

If you don't have the Flathub remote set up yet:

```bash
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
```

</Tabs.Tab>

<Tabs.Tab>

[Download the `.deb`](https://app.jan.ai/download/latest/linux-amd64-deb), then install it:

```bash
sudo apt-get install ./Jan_{version}_amd64.deb
```

Or with `dpkg`:

```bash
sudo dpkg -i ./Jan_{version}_amd64.deb
```

</Tabs.Tab>

<Tabs.Tab>

[Download the AppImage](https://app.jan.ai/download/latest/linux-amd64-appimage), then run it:

```bash
chmod +x ./Jan_{version}_amd64.AppImage
./Jan_{version}_amd64.AppImage
```

</Tabs.Tab>
</Tabs>

## Updating Jan

How Jan updates depends on which package you installed:

<Tabs items={['Flatpak (recommended)', 'AppImage', '.deb (Ubuntu/Debian)']}>
<Tabs.Tab>

Flatpak updates through Flathub along with the rest of your system. The in-app updater is disabled — your package manager handles it:

```bash
flatpak update ai.jan.Jan
```

</Tabs.Tab>
<Tabs.Tab>

The AppImage supports Jan's **built-in auto-updater**. When a new release is available, Jan downloads and applies it in place, then restarts.

</Tabs.Tab>
<Tabs.Tab>

The `.deb` package is **not updated by the in-app updater** — the auto-updater only ships the AppImage as the Linux update artifact. Update the `.deb` manually by downloading the latest package and reinstalling. Replace `{version}` with the version in the newly downloaded filename:

```bash
sudo apt-get install ./Jan_{version}_amd64.deb
```

Your data and settings (by default under `~/.local/share/Jan`) are preserved across reinstalls.

</Tabs.Tab>
</Tabs>

## Compatibility

- **OS:** Debian/Ubuntu, Fedora/RHEL, Arch, openSUSE
- **CPU:** AVX2 required — Intel Haswell (2013+), AMD Excavator (2015+)
- **Memory:** 8GB minimum (16GB recommended)
- **GPU:** 6GB VRAM minimum
- **Storage:** 10GB free space minimum

## Jan Data Folder

Jan stores all your data locally — downloaded models, conversation threads, settings, and logs generated from using the app. Nothing is sent to the cloud.

Default locations depend on the installation method:

| Installation | Data folder | Configuration file (records the data folder location) |
| --- | --- | --- |
| Flatpak | `~/.var/app/ai.jan.Jan/data/Jan/data` | `~/.var/app/ai.jan.Jan/data/Jan/settings.json` |
| `.deb` / AppImage | `~/.local/share/Jan/data` | `~/.local/share/Jan/settings.json` |

Jan resolves these locations via `XDG_DATA_HOME` unless overridden. [Flatpak sets its own XDG directories](https://docs.flatpak.org/en/latest/conventions.html#xdg-base-directories) under `~/.var/app/ai.jan.Jan/`, including `data` and `config`. Older configuration files may be recovered from `~/.var/app/ai.jan.Jan/config/Jan/` (Flatpak) or `~/.config/Jan/` (native, via `XDG_CONFIG_HOME`). A custom data folder can be elsewhere; check its location in Jan before removing data.

See [Jan Data Folder](/desktop/data-folder) for details.

### Step 1: Verify Hardware & Install Dependencies

**1.1. Check GPU Detection**

```sh
lspci | grep -i nvidia
```

**1.2. Install Required components**

**NVIDIA Driver:**

1. Install the [NVIDIA Driver](https://www.nvidia.com/en-us/drivers/), ideally via your package manager.
2. Verify:

```sh
nvidia-smi
```

Jan bundles its CUDA 13 engine and runtime libraries. Installing the CUDA Toolkit, GCC, or a custom `LD_LIBRARY_PATH` is not required to run the packaged app. GPUs or drivers that cannot use CUDA 13 use Vulkan instead. For Vulkan fallback, install your distribution's Vulkan loader and a Vulkan-capable NVIDIA driver; since v0.8.6, the AppImage uses your system's Vulkan loader.

### Step 2: Enable GPU Acceleration

Navigate to **Settings** (<Settings width={16} height={16} style={{display:"inline"}}/>) > **Hardware** > **GPUs** and turn on your GPU's switch if disabled. Jan uses the backends bundled with the app; there is no backend version to download or select in Model Providers. See [Hardware Backends](/desktop/local-engine/llama-cpp#hardware-backends).

## Uninstall Jan

Removal commands:
<Tabs items={['Flatpak', '.deb (Ubuntu/Debian)', 'AppImage']}>
<Tabs.Tab>

To uninstall while keeping your data:

```bash
flatpak uninstall ai.jan.Jan
```

To also remove the current user's Flatpak data:

<Callout type="warning">
`--delete-data` permanently deletes `~/.var/app/ai.jan.Jan/`, including models, conversations, settings, and logs stored there, and resets the app's permissions. Back up anything you need first. Do not use it if you are keeping another Flatpak installation or branch of Jan with the same app ID: they share this data.
</Callout>

```bash
flatpak uninstall --delete-data ai.jan.Jan
```

As explained in the [Flathub uninstall guide](https://docs.flathub.org/docs/for-users/uninstallation), data outside this directory is not removed. Leave native Jan directories (`~/.local/share/Jan` and `~/.config/Jan`) and any custom data folders intact unless you separately intend to delete them; they may be used by another installation.
</Tabs.Tab>
<Tabs.Tab>

```bash
sudo apt-get remove jan
rm -rf ~/.local/share/Jan   # data folder (models, threads, logs)
rm -rf ~/.config/Jan        # app configuration
```
</Tabs.Tab>
<Tabs.Tab>

```bash
rm ./Jan_{version}_amd64.AppImage
rm -rf ~/.local/share/Jan   # data folder (models, threads, logs)
rm -rf ~/.config/Jan        # app configuration
```
</Tabs.Tab>
</Tabs>

<Callout type="warning">
The `rm -rf` commands in the native-install tabs permanently delete the default native data and configuration directories, which may be shared by `.deb` and AppImage installations. Omit them to preserve data or another installation. They do not cover custom data folders or overridden XDG paths.
</Callout>
