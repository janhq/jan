<Callout type="warning">
**Jan requires a Mac with Apple Silicon (M1 or newer). Intel-based Macs are not supported.**

Jan still opens on an Intel Mac, but its local AI engine is built for Apple Silicon only. On an Intel Mac:

- Local models do not load.
- Attaching documents (PDF, DOCX and other files) to a chat fails, because Jan indexes them with a local embedding model.
- The [Local API Server](/desktop/api-server#prerequisites) cannot serve local models.

These features fail with an error such as `Bad CPU type in executable (os error 86)`.

The download is labeled "universal" because the app itself starts on both kinds of Mac. That does not mean Intel Macs are supported.
</Callout>

### Check your Mac

Open the Apple menu and choose **About This Mac**:

- **Chip: Apple M1, M2, M3, M4** or newer: supported.
- **Processor: Intel**: not supported.

### If you have an Intel Mac

- Intel Macs have not been supported since v0.8.0. Since [v0.8.5](https://github.com/janhq/jan/releases/tag/v0.8.5), local models do not run on them at all. If you rely on local models on an Intel Mac, stay on v0.8.4.
- On newer versions, chatting with remote or [custom providers](/desktop/remote-models/custom-endpoint) may work, but it is not supported or tested on Intel Macs.

## Install Jan

<Steps>

### Download

<DownloadButton href="https://app.jan.ai/download/latest/mac-universal">Download Jan for Mac</DownloadButton>

### Install

1. Open the Jan installer (`.dmg` file)
2. Drag Jan to **Applications**
3. Launch Jan

</Steps>

## Compatibility

### Minimum Requirements
- **Operating System:** macOS 13.6 or higher
- **Memory:**
  - Model fit depends heavily on **quantization**, context length, and how much memory macOS is already using.
  - 8GB → typically up to **3B** models comfortably; some **7B** models may fit only at aggressive low-bit quantizations
  - 16GB → typically up to **7B** models comfortably; some **13B** models may fit at lower quantizations
  - 32GB → typically up to **13B** models comfortably, with more headroom for higher quantizations, larger context windows, or multitasking
- **Storage:** 10GB+ free space

### Mac Performance Guide

- **Apple Silicon (M1, M2, M3, M4)**: supported, with Metal acceleration enabled by default. **M4 and newer** chips deliver the best performance.
- **Intel**: not supported. See [the warning above](#check-your-mac).

## Jan Data Folder

Jan stores all your data locally — downloaded models, conversation threads, settings, and logs generated from using the app. Nothing is sent to the cloud.

Default location:

```sh
~/Library/Application\ Support/Jan/data
```
See [Jan Data Folder](/desktop/data-folder) for details.

## Uninstall Jan

<Steps>

### Step 1: Remove Application
1. Close Jan if it's running
2. Open **Finder**
3. Go to **Applications**
4. Find Jan
5. Pick your removal method:
  - Drag to **Trash**
  - Right-click → **Move to Trash**
  - **Command-Delete**

### Step 2: Clean Up Data (Optional)

Run this in **Terminal** to remove all data:
```bash
rm -rf ~/Library/Application\ Support/Jan/data
```
</Steps>

<Callout type="warning">
This permanently deletes all data. Create backups if needed.
</Callout>
